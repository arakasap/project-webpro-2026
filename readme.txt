G5 : ระบบสั่งอาหารร้านอาหารอีสาน
===============================

เริ่มใช้งาน
-----------
ดับเบิลคลิกไฟล์ start.bat ที่อยู่ในโฟลเดอร์นี้
หรือเปิด โฟลเดอร์ใน command prompt แล้วพิมพ์ nodemon index.js

เริ่มเว็บเซิร์ฟเวอร์ โดยใช้พอร์ต 3000 เป็นค่าเริ่มต้น

หากต้องการหยุดเซิร์ฟเวอร์ ให้กด Ctrl+C ในหน้าต่างที่เปิดขึ้น

หน้าเว็บ
-------
- หน้าลูกค้าทั่วไป: http://localhost:3000/ (Default โต๊ะ 1)
- ลิงก์ประจำโต๊ะ 1: http://localhost:3000/table/1
- ลิงก์ประจำโต๊ะอื่น: เปลี่ยนเลขท้าย URL ให้ตรงกับหมายเลขโต๊ะ 
เช่น
  http://localhost:3000/table/2 (โต๊ะ 1 - 20)

- หน้าครัว/พนักงานเสิร์ฟ: http://localhost:3000/kitchen

- หน้าแคชเชียร์: http://localhost:3000/cashier


หน้าครัวและพนักงานเสิร์ฟต้องใช้รหัสพนักงานที่กำหนดไว้ในฐานข้อมูลของระบบ
โดยกำหนดให้ 
111 คือรหัสของพนักงานครัว
222 คือรหัสของพนักงานเสิร์ฟ

โครงสร้างหลัก
-------------
- index.js                 จุดเริ่มต้นเว็บเซิร์ฟเวอร์และการเชื่อมต่อฐานข้อมูล
- start.bat                ติดตั้ง dependencies (ถ้าจำเป็น) และเริ่มเซิร์ฟเวอร์
- routes/                  เส้นทางการทำงานของลูกค้า แคชเชียร์ และครัว
- views/                   หน้าเว็บที่ใช้ EJS
- public/                  ไฟล์ CSS และทรัพยากรหน้าเว็บ
- utils/                   ฟังก์ชันช่วยเหลือ เช่น การสร้างภาพใบเสร็จ
- utils/fonts/             ฟอนต์ Prompt สำหรับแสดงผลภาษาไทยบนใบเสร็จ
- database.db              ฐานข้อมูล SQLite ของระบบ
